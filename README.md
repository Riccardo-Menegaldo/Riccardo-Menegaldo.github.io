# Riccardo Menegaldo

My personal website, built as a neon pixel art video game: title screen, levels, skills, PlutonX, Formula 1, an animated pixel story and a chiptune soundtrack.

Plain HTML, CSS and JavaScript in a single file. No build step and no dependencies (only Google Fonts).

## Publish on GitHub Pages

1. Keep this repository named `Riccardo-Menegaldo.github.io`.
2. Commit `index.html` and push to the `main` branch.
3. In the repository go to Settings > Pages and choose "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site goes live at https://riccardo-menegaldo.github.io

## Things to personalise in `index.html`

- Skill percentages in "Level 2" (search for `--v:`), they are self-rated.
- Anything else you want to change: search for the text in the file.

## Controls

- Enter or the Press Start button: begin.
- M: music on and off.
- Secret: up, up, down, down, left, right, left, right, B, A.
